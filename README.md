# 🐍 Snake Game

A classic snake game built with HTML5 canvas and vanilla JavaScript. Play directly in your browser with no dependencies required!

![Snake Game](https://img.shields.io/badge/Game-Snake-brightgreen) ![HTML5](https://img.shields.io/badge/HTML5-Canvas-orange) ![JavaScript](https://img.shields.io/badge/JavaScript-Vanilla-yellow)

## 🎮 Features

- **Classic Gameplay**: Control the snake, eat food, and grow longer
- **Smooth Controls**: Use arrow keys or WASD for movement
- **Progressive Difficulty**: Speed increases as you score more points
- **Pause/Resume**: Press spacebar to pause the game anytime
- **High Score Tracking**: Your best score is saved locally
- **Modern Design**: Beautiful gradient UI with smooth animations
- **Visual Polish**: Snake with animated eyes, glossy food, and grid background

## 🚀 How to Play

1. Open `index.html` in any modern web browser
2. Use **Arrow Keys** or **WASD** to control the snake's direction
3. Eat the red food to grow longer and score points
4. Avoid hitting the walls or your own tail
5. Press **Spacebar** to pause/resume the game

## 🎯 Game Rules

- Each food eaten gives you **10 points**
- The snake moves faster as you score more
- Game ends if you hit a wall or collide with yourself
- Your high score is automatically saved

## 🛠️ Technology

- Pure HTML5 Canvas for rendering
- Vanilla JavaScript (no frameworks or libraries)
- CSS3 for modern styling with gradients and animations
- LocalStorage API for high score persistence

## 📦 Installation

No installation required! Just download and open:

```bash
# Clone the repository
git clone https://github.com/mohit-malpote/snake-game.git

# Navigate to the directory
cd snake-game

# Open in your default browser
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Or simply download `index.html` and double-click to play!
